# 🤝 Contribution Guidelines

Thank you for your interest in contributing to **Deutsch Entdecker**!
Every contribution—big or small—helps our community learn and grow together.

---

## 🚀 How to Contribute

1. **Fork this repository** to your own GitHub account.
2. **Create a new branch** for your change:
   ```bash
   git checkout -b my-new-contribution
   ```

3. **Make your changes** (e.g., edit a file, add content, fix an error).

4. **Commit your changes** with a clear message:

   ```bash
   git commit -m "Add new vocabulary: das Haus"
   ```
5. **Push your branch** to your fork:

   ```bash
   git push origin my-new-contribution
   ```
6. **Open a Pull Request (PR)** and describe what you changed.

---

## ✍️ Content Standards

To keep our resources consistent and useful:

* **Clarity first** – Use simple, learner-friendly language.
* **Vocabulary format** – Follow this pattern:

  ```markdown
  - **das Haus, -¨er** — house, home
  ```
* **Grammar & rules** – Always include at least one example sentence.
* **Respect & collaboration** – Be constructive and encouraging in discussions.

---

## 💡 Tips for Contributors

* Small improvements (fixing typos, formatting, etc.) are just as valuable as big ones.
* If you’re unsure about a change, open an **Issue** to discuss it before creating a PR.
* Contributions in **Deutsch, English, or Français** are welcome.

---

We’re excited to see your contributions and appreciate your support in making this project better for everyone!
